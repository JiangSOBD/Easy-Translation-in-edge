# Lingua Selection（Edge）

无构建步骤的 Manifest V3 Edge 扩展原型。当前实现包括网页划词浮层、所在句子辅助翻译、译文和 IPA 音标、AI 概念解读、模型设置及网站授权。

## 在 Edge 中本地运行

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 开启“开发人员模式”。
3. 选择“加载解压缩的扩展”，选择本项目目录。
4. 打开扩展设置，填写模型 API 地址、模型名称和 API Key。保存时按提示授权模型服务域名。
5. 在设置页授权要使用的网页（单站或所有 HTTP/HTTPS 网站）。重新加载已打开的网页。
6. 在普通网页中选中英文文本，浮层会自动翻译并显示音标；点击“AI 概念解读”可查询概念。

DeepSeek、Kimi 和智谱有预设地址与模型名；服务商接口会变更，若预设模型不可用，可在设置页修改模型名或 API 地址。自定义项按 OpenAI Chat Completions 兼容格式请求。

## 隐私和使用边界

- 选区完成后自动发起翻译请求，仅附带选区所在句子；AI 概念解读和整页背景仍需用户主动点击/启用。
- 浮层在空闲时不会自动消失；点击关闭、按 Escape、点击浮层外或选中另一段文字时关闭或更新。
- 成功翻译的文本会在当前页面加下划线并保留结果；再次点击标记直接显示缓存。缓存保留到页面关闭，不设条数上限；页面内容变化导致高亮失效时，已有译文仍保留。翻译框可拖动。
- API Key 使用 `storage.local` 保存，不使用同步存储。浏览器本地扩展存储并非硬件密钥保险箱。
- 模型调用会把必要文本直接发送给配置的服务商，并可能产生费用。
- 音标由模型在翻译响应中提供，是近似结果；当前版本没有接入独立授权词典数据源。
- 邮件草稿通过用户设备上的邮件客户端创建。飞书发送、模型流式输出和账户/云同步尚未实现。

## 验证

本项目不依赖打包器。可以用 Edge 加载解压缩扩展验证交互；仓库环境若没有 Node.js，则无法执行 Node 驱动的自动化测试或构建。
